      Get set up

      1. Install the player app once on your phone: iteration-player-v0.2-debug.apk
        Direct download from this site — open the link on your phone and install it, then it just works.
      2. Start the watcher with one command:
        ~/workspace/rapid-iteration/watch.sh start
        If the computer restarts, run it again.
      3. Edit code, save, and watch it go live. Every save becomes a new version here — and on your phone.
